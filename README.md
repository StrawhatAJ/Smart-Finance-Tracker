# Smart Finance Tracker

A Django-based finance tracking web app with a REST API.

## Setup

1. Clone the repo
   git clone https://github.com/YOUR_USERNAME/smart-finance-tracker.git

2. Create and activate a virtual environment
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # Mac/Linux

3. Install dependencies
   pip install -r requirements.txt

4. Create a .env file with your secret key
   DJANGO_SECRET_KEY=your-secret-key-here

5. Run migrations
   python manage.py migrate

6. Start the server
   python manage.py runserver""# Smart-Finance-Tracker"
